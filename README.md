## Что здесь

Проект направлен на аналитику в канале Прайм. 
Расчет производится на выделенном сегменте, его стандартный состав:
| Поле | Что это |
|---|---|
| `row_id` | идентификатор строки |
| `actor_id` | участник — тот, чьи это строки |
| `day` | день события, тип `datetime.date` |
| `ok` | состоялось ли событие: `True` или `False` |
| `value` | сколько: деньги, минуты или часы, тип `Decimal` |

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```

## Что здесь считается

На основе сегмента рассчитываются следующие мониторинг-задачи:
1. Информация о выделенном сегменте
2. Контроль клиентов с неуспешными и успешными операциями
3. Самый активный день недели 
4. Розыгрыш приза на основе активности клиента
5. Пиковые дни
6. Вычисление даты половины выручки или перекоса в суммах среди месяца
7. Очистка данных от неправильного заполнения
8. Применение весов к суммам транзакций
